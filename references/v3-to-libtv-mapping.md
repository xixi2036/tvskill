# v3 → TVMao 完成提示词映射（兼容文件名）

本文件是 v3 知识到 TVMao 交付的**映射说明**。目录与文件名暂时保留 `libtv`，用于兼容既有链接；运行后端已经迁移。冲突裁决以 `SKILL.md` 与 TVMao 画布合同为准。

## 粒度映射

| v3 概念 | TVSkill / TVMao 概念 | 规则 |
|---|---|---|
| 内部 `cNN` | 段内的内部剪辑节拍 | 只服务导演推理，**不进最终代码块**，更不写绝对时间码；密集时拆节点而非合并画面 |
| `storyboard[]` | Markdown 中一个“生成段 VNN” | 一次 TVMao video-generator 生成，通常 4–15 秒 |
| 顶层角色/场景/物品 | 公共素材清单与各段 Mixed 上传表 | 使用稳定语义名与人能识别的素材名 |
| `@[角色/场景/物品-名称]` | Markdown `@[语义资产] {{Mixed N}}` | 兼容 DSL；同步时编译为 TVMao node-id mention，运行时序列化为 `图片N/视频N/音频N` |
| `storyboard[].prompt` | `text` 代码块中的完成提示词 | 编译后写入 TVMao `params.prompt` |
| 空间母版 | 人物位置或场景 Mixed 素材 | 同场多段时锁定空间、座位、功能前方、家具/人体朝向、轴线和主光 |
| 内部边界 `Bnnn` | “衔接”、状态交接与段间衔接总表 | 交付可比较的连续键、入点、出点和自然语言剪辑说明 |

## 继续保留的 v3 能力

- 语音账本先于分镜，正文零改写并正反向对账。
- 原子镜头以 2–3 秒为主，动作与台词并行核算。
- 整集保持一个导演声部与清楚的升级、转折、高潮和释放。
- 一镜一意图、一起幅、一落幅、一个主运镜；移动镜遵循稳—动—稳。
- 世界坐标、轴线、人物动线、道具归属、光源和环境声连续。
- 独立视频节点只在动作完成、完整意群、明确反应或转场处切分。
- 普通缺陷词不堆叠，优先使用正向状态锁。

## 废止规则

1. 不输出任何 JSON 产物，不提供 JSON 代码块或 JSON 文件链接。
2. 不创建 `candidate.json + submit_artifact` 交付链。
3. 不把 script rows 或 script 节点作为人工交付中心。
4. Markdown 不直接混用普通 `@图片N` 与 Mixed DSL；规范的 `@[语义资产] {{Mixed N}}` 必须保留，TVMao 同步器负责写入带真实节点 ID 的画布 mention。禁止在 Markdown 编造裸素材 ID。
5. 不在提示词之外另放一份“精确台词真值”；最终提示词自身必须包含逐字台词。
6. 不要求用户提供全局 `DURATION_SEC`。

## 时长决策

- 旧 v3 的外部 `DURATION_SEC` 废止；不得询问用户，也不得预设全片统一片段长度。
- LLM 先按 4–5 字/秒核算台词，再加入动作完成、稳定入幅与完成落幅所需时间。
- 默认在 4–15 秒内选择满足自然表演的最短整数时长。
- 用户指定模型时先读取实时 schema；模型只允许离散时长时，从允许集合选择。
- 超过模型上限时在自然完成点拆开。

## 人工参考图对账

对每个视频节点独立执行：

1. 每段 Mixed 上传表从 `Mixed 1` 连续编号；
2. 在 TVMao 画布按同序连接图片、音频和必要视频输入节点；
3. 同步器把 `@[语义资产] {{Mixed N}}` 编译为对应媒体类型的官方引用；
4. 用 `tvmao edge list --to` 回读入边顺序，并核对编译引用。

素材表、编译引用和真实入边顺序任一不一致，节点都不能称为可直接使用。
