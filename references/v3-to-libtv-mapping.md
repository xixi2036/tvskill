# v3 → LibTV 完成提示词映射

本文件是适配优先级最高的覆盖层。`references/v3/` 中导演、时长、对白、连续性和视觉规则继续生效；旧 JSON schema、资产数组、token 和提交协议全部失效。

## 粒度映射

| v3 概念 | TVSkill / LibTV 概念 | 规则 |
|---|---|---|
| 内部 `cNN` | 段内的 `△（镜头参数）（时间码）` | 内部原子镜头编译为逐镜正文，不交付 `cNN` |
| `storyboard[]` | Markdown 中一个“生成段 VNN” | 一次 LibTV 视频生成，通常 4–15 秒 |
| 顶层角色/场景/物品 | 公共素材清单与各段 Mixed 上传表 | 使用稳定语义名与人能识别的素材名 |
| `@[角色/场景/物品-名称]` | `@[语义资产] {{Mixed N}}` | 人工按表上传/连接，提示词保留 LibTV Mixed 绑定 |
| `storyboard[].prompt` | `text` 代码块中的完成提示词 | 整块复制到 LibTV 视频生成节点 |
| 空间母版 | 人物位置或场景 Mixed 素材 | 同场多段时锁定空间、座位、功能前方、家具/人体朝向、轴线和主光 |
| 内部边界 `Bnnn` | “衔接”、状态交接与段间衔接总表 | 交付可比较的连续键、入点、出点和自然语言剪辑说明 |

## 继续保留的 v3 能力

- 语音账本先于分镜，正文零改写并正反向对账。
- 原子镜头以 2–3 秒为主，动作与台词并行核算。
- 整集保持一个导演声部与清楚的升级、转折、高潮和释放。
- 一镜一意图、一起幅、一落幅、一个主运镜；移动镜遵循稳—动—稳。
- 世界坐标、轴线、人物动线、道具归属、光源和环境声连续。
- 独立视频节点只在动作完成、完整意群、明确反应或转场处切分。
- 普通缺陷词不堆叠，优先使用正向状态锁。

## 废止规则

1. 不输出任何 JSON 产物，不提供 JSON 代码块或 JSON 文件链接。
2. 不创建 `candidate.json + submit_artifact` 交付链。
3. 不把 script rows 或 script 节点作为人工交付中心。
4. 不输出旧式 `@图片N`、裸素材 ID 或无上传表对应的 `{{Mixed N}}`；规范的 `@[语义资产] {{Mixed N}}` 必须保留。
5. 不在提示词之外另放一份“精确台词真值”；最终提示词自身必须包含逐字台词。
6. 不要求用户提供全局 `DURATION_SEC`。

## 时长决策

- 旧 v3 的外部 `DURATION_SEC` 废止；不得询问用户，也不得预设全片统一片段长度。
- LLM 先按 4–5 字/秒核算台词，再加入动作完成、稳定入幅与完成落幅所需时间。
- 默认在 4–15 秒内选择满足自然表演的最短整数时长。
- 用户指定模型时先读取实时 schema；模型只允许离散时长时，从允许集合选择。
- 超过模型上限时在自然完成点拆开。

## 人工参考图对账

对每个视频节点独立执行：

1. 每段 Mixed 上传表从 `Mixed 1` 连续编号；
2. 人工在 LibTV 画布按同序上传或连接图片、音频和必要视频；
3. 提示词使用 `@[语义资产] {{Mixed N}}` 绑定同一素材职责；
4. 粘贴后核对界面媒体顺序与 Mixed 编号一致。

素材表、提示词 Mixed 指代和真实媒体顺序任一不一致，节点都不能称为可直接使用。
