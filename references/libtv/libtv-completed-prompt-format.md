# LibTV 完成提示词规范

本规范融合《三合一提示词.docx》的人工交付结构与 Seedance 2.0 官方优化规则。Markdown 保留场次、时长、Mixed 表和衔接；真正复制到模型输入框的代码块使用官方三段论。

节点默认：`Seedance 2.0 Fast VIP`、`9:16`、`480P`。声音按制作路线开启或关闭。

## 1. Markdown 外层

每个生成段写：

```markdown
## 生成段 V01｜入场

- 段号：3-1-A
- 时长：10秒
- 连续组：CG-ZCLASS-DAY01
- 前置段：EP01-V03
- 提示词二审：已通过
- 交付等级：正式
- 制作路线：绑定逐句音频原生同步
- 风险标签：同步对白
- 运行状态：可运行
- 连续性模式：场景母版
- 声音：开启
- 文字策略：无画面文字
- 音色状态：已绑定李威逐句音频

### Mixed 上传顺序
### LibTV 完成提示词（整块复制）
### 衔接
### 状态交接
### 剧本事实对账
```

场次、绝对时间、段时长、内部节奏和语音对账留在 Markdown 外层，不进入模型代码块。
全集初稿完成后增加全剧连续性声明和母版，按人物、服装、场景、功能拓扑、人群、道具、
时间线和轴线连续键做第二遍检查；二审发现的问题必须回写提示词或拆段。

## 2. Mixed 独立资产

推荐顺序：

1. 主要人物独立身份图；
2. 其他人物各自独立身份图；
3. 独立音色或合法台词音频；
4. 干净首帧或已验收续接帧；
5. 与当前人数一致的场景状态图；
6. 独立道具或动作参考。

硬规则：

- 不同人物不得共用人物图或 Mixed；
- 人物图不得与首帧、场景状态图、道具图共用 Mixed；
- 位置图、轨迹图、构图图、平面图、箭头、色块、假人和文字标注图只用于内部规划，严禁进入 Mixed；
- 干净首帧/续接帧必须是单一时刻的真人实拍式画面，不含标记、界面和规划信息；
- 场景状态图的人数必须与本段可见人数一致；空场景不能支持全班可见镜头；
- 功能场景群像必须使用已验收的占座朝向图，并在提示词中正向锁定功能前方、家具朝向、
  人体下半身默认方向和允许的局部转动；
- 可识别群像确需锁定时使用独立群像图，不拿主角图替代；
- 同一人物的大头照和全身照可以是两个 Mixed，但禁止三视图和多人拼图；
- 对白人物可增加独立三分之四侧脸近照；避免只用正面立正、直视镜头的全身图控制眼神；
- Mixed 从 1 连续编号，表格与代码块一一对应。

## 3. 官方三段论代码块

```text
现代学院教室白日文戏，右侧冷白窗光、弱暖顶灯。将 @[单知影] {{Mixed 1}} 中黑色低马尾和深蓝制服定义为 <主体1>；将 @[李威] {{Mixed 2}} 中短黑发和深蓝制服定义为 <主体2>；@[李威-逐句音频] {{Mixed 3}} 只控制 <主体2> 本句的音色、节奏与口型，不继承其它台词和背景声。参考 @[首帧-3-1-B] {{Mixed 4}} 的干净构图、人物位置和真实视线对象；将 @[场景状态-Z班-占座] {{Mixed 5}} 定义为 <场景1>，只参考空间、物理光线、当前人数以及已验收的教学朝向。黑板固定在教室前墙，课桌、座椅和就座学生的骨盆、膝盖、双脚始终朝向黑板。

单一连续镜头，无剪切。中近景，稳定三分之四侧机位。<主体2> 听见教室安静后才开口，视线落在 <主体1> 的右肩背；他说 {精确原文台词}，一口自然说完；说完恢复鼻息，继续听着 <主体1> 的方向，右手自然留在桌沿。<教室低声场>。（全程无背景音乐）

真人实拍，右侧冷白窗光和弱暖顶灯方向固定。<主体1> 与 <主体2> 各只出现一人；保持人物身份、制服、座位、眼神轴线和手中道具一致。保持无字幕，不生成可辨识文字、水印或 Logo。
```

## 4. 模型语法

- 使用三段论：设定与定义 → 镜头动作 → 风格与约束；
- 简单单镜任务可以压缩为一段；
- 单一事件的同步对白写明“单一连续镜头，无剪切”，不写镜号，只含一位说话人和一个自然意群；
- 确需片内剪切时使用行首精确 `Shot 1:`、`Shot 2:`；禁止旧 `镜头N：`，也不得和连续单镜声明混用；
- 多镜由时间/空间事件密度决定；10–15 秒原生生成通常只承载 2–3 个清楚 `Shot N:`。
  v3 内部 2–3 秒剪辑节拍不等于模型 Shot 数量；
- 多镜原生声画同出时，每个 `Shot N:` 只允许一位说话人和一个自然意群，并绑定其独立音色；
- OS/VO 不与口型对白放在同一个 Shot；走位、递物、高速道具、群体反应、特效和精确文字不与同步对白放在同一个 Shot；
- 每镜一个主运镜；
- 动作写部位、幅度、速度、方向和落点；
- 同步对白写开口触发、具体眼神对象和活状态；身体变化与声音控制各最多一个，也都允许为零；
- 六字以内短句一口自然说完，禁止强行放慢、停半拍、一字一顿或拖长；
- 多人镜头只设一个表演焦点，最多一名反应人物，其余人保持持续微动；
- 用 `<主体N>` 描述动作，避免资产引用裸接动词；
- 台词用 `{}`；
- 音效用 `<>`；
- BGM 用 `（）`；
- 零文字任务禁止 `【】`；
- 不写 `00:00.00–00:03.00`、`第5秒`等绝对时间。

## 5. 质量守卫

代码块末段必须覆盖：

- 真人实拍与整体视觉风格；
- 当前场景的物理光源；
- 当前最脆弱的人脸、嘴型、手或道具状态；
- 多人防分身、防双胞胎、防身份交换；
- 无字幕、无可见文字、无水印、无 Logo；
- 当前场景特有的轴线、道具、服装和光向约束。

分辨率由节点参数控制。不要把“高清、8K、细节丰富、电影质感、色彩自然、
光影柔和”作为固定套话，也不要把优化分析、内部账本或无关缺陷词复制进 LibTV。
