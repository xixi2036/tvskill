# LibTV 完成提示词规范

本规范融合《三合一提示词.docx》的人工交付结构与 Seedance 2.0 官方优化规则。Markdown 保留场次、时长、Mixed 表和衔接；真正复制到模型输入框的代码块使用官方三段论。

节点默认：`Seedance 2.0 Fast VIP`、`9:16`、`480P`。声音按制作路线开启或关闭。

## 1. Markdown 外层

每个生成段写：

```markdown
## 生成段 V01｜入场

- 段号：3-1-A
- 时长：10秒
- 连续组：CG-ZCLASS-DAY01
- 前置段：EP01-V03
- 提示词二审：已通过
- 交付等级：正式
- 制作路线：绑定逐句音频原生同步
- 风险标签：同步对白
- 运行状态：可运行
- 连续性模式：场景母版
- 声音：开启
- 文字策略：无画面文字
- 音色状态：已绑定李威逐句音频

### Mixed 上传顺序
### LibTV 完成提示词（整块复制）
### 衔接
### 状态交接
### 剧本事实对账
```

`音色状态` 有两种合法写法：已关联真实音频写"已绑定<素材名>"；音色尚未由人工上传时写
"待关联｜占位槽：<角色名>-音色参考（待人工上传）"，此时该段 `运行状态` 必须是 `阻塞`。
两者必须与 Mixed 表自洽：写"待关联"就必须有对应占位行，有占位行就不能标"已绑定"。

场次、绝对时间、段时长、内部节奏和语音对账留在 Markdown 外层，不进入模型代码块。
全集初稿完成后增加全剧连续性声明和母版，按人物、服装、场景、功能拓扑、人群、道具、
时间线和轴线连续键做第二遍检查；二审发现的问题必须回写提示词或拆段。

## 2. Mixed 独立资产

推荐顺序：

1. 主要人物独立身份图；
2. 其他人物各自独立身份图；
3. 独立音色或合法台词音频；
4. 干净首帧或已验收续接帧；
5. 确有必要时使用干净单视图视频场景锚；
6. 独立道具或动作参考。

硬规则：

- 不同人物不得共用人物图或 Mixed；
- 人物图不得与首帧、视频场景锚、道具图共用 Mixed；
- 位置图、轨迹图、构图图、平面图、箭头、色块、假人和文字标注图只用于内部规划，严禁进入 Mixed；
- 干净首帧/续接帧必须是单一时刻的真人实拍式画面，不含标记、界面和规划信息；
- 带标题、分格、文字、灰色/剪影占位人的场景规划母板禁止进入视频 Mixed，不能靠负向提示洗净；
- 视频场景锚必须是无文字、无分格、无占位人的干净单视图；多人同步对白还必须有 9:16 干净首帧；
- 功能场景群像必须使用已验收的占座朝向图，并在提示词中正向锁定功能前方、家具朝向、
  人体下半身默认方向和允许的局部转动；
- 可识别群像确需锁定时使用独立群像图，不拿主角图替代；
- 音色尚未上传时，用一行音色占位槽占住该说话人的位置：素材写"<角色名>-音色占位槽（待人工上传）"、
  类型写"音频（待上传）"、绑定语义仍写该角色的音频语义名；占位槽只允许存在于未同步到画布的
  Markdown 里，画布节点上不得出现空占位；
- 同一角色的 16:9 三视图母板可作为一个身份 Mixed 长期复用，但必须排除白底、多分格、原站姿和直视视线；禁止多人拼图；
- 对白人物可增加独立三分之四侧脸近照；避免只用正面立正、直视镜头的全身图控制眼神；
- Mixed 从 1 连续编号，表格与代码块一一对应。

【声音设计】0-2秒：教室低频环境底噪与远处走廊人声；2-4秒：<主体2> 的原声台词与轻微椅面摩擦声；4-10秒持续：环境底噪延续到落幅。仅生成人声与环境音效，不要 bgm。

【关键约束】机位铁律：全程稳定三分之四侧，不推不拉不摇。身份铁律：<主体1> 与 <主体2> 各只出现一人，不得交换身份或制服。朝向铁律：就座学生的骨盆、膝盖、双脚始终朝向黑板，回看只转眼、头、肩。光向铁律：右侧冷白窗光与弱暖顶灯方向全程固定。

## 4. 模型语法

- 使用三段论：设定与定义 → 镜头动作 → 风格与约束；
- 简单单镜任务可以压缩为一段；
- 连续单镜只用于有明确不中断表演价值的单一事件，写明“单一连续镜头，无剪切”；10 秒以上还必须写`长镜头叙事意图：...`；
- 确需片内剪切时使用行首精确 `Shot 1:`、`Shot 2:`；禁止旧 `镜头N：`，也不得和连续单镜声明混用；
- 多镜由时间/空间事件密度决定，按爆款短剧约 2.1 秒平均刀长配置：10–13 秒通常 4–7 个、14–15 秒通常 5–8 个清楚 `Shot N:`，2 秒镜为主、3 秒次之且功能明确；
- 多镜原生声画同出时，每个 `Shot N:` 只允许一位说话人和一个自然意群，并绑定其独立音色；
- OS/VO 不与口型对白放在同一个 Shot；走位、递物、高速道具、群体反应、特效和精确文字不与同步对白放在同一个 Shot；
- 每镜一个主运镜；
- 动作写部位、幅度、速度、方向和落点；
- 同步对白写开口触发、具体眼神对象和活状态；身体变化与声音控制各最多一个，也都允许为零；
- 六字以内短句一口自然说完，禁止强行放慢、停半拍、一字一顿或拖长；
- 多人镜头只设一个表演焦点，最多一名反应人物，其余人保持持续微动；
- 用 `<主体N>` 描述动作，避免资产引用裸接动词；
- 台词用 `{}`；
- 音效用 `<>`；
- BGM 用 `（）`；
- `【】` 只允许三类结构标记：`【阶段N…】`、`【声音设计】`、`【关键约束】`；其余任何
  `【…】` 文本一律禁止，避免被当作画面文字渲染；
- 不写 `00:00.00–00:03.00`、`第5秒`等绝对时间；唯一例外是 `【声音设计】` 段内部的
  段内相对秒层（`0-2秒`/`2-4秒`/`4-10秒持续`），它只描述音轨分层，不给画面下剪辑时间表。

## 4b. 正式段结构六件套

官方三段论只规定信息顺序，不保证成片水平。真实上线成片的提示词在三段论之上稳定携带
六个结构元素；缺其中任何一个，提示词仍会"结构合规但通用平庸"。正式段必须六项齐全，
预览段可省略。六件套依附三段论，不另起一套语法：

| 元素 | 落在三段论的哪一段 | 写法 |
|---|---|---|
| 开篇风格锁定行 | 第一段首行 | 参考坐标＋胶片/质感＋色调，例如"…kinetic chase aesthetics + 低饱和去饱和 + Kodak Vision3 35mm film grain"；全连续组复用同一条，不逐段换同义词 |
| 逐资产视觉锚定语 | 第一段每个资产 | 在官方"定义为 `<主体N>`"之后补"该图作为 `<主体N>` 的视觉锚定，…严格按此图渲染，不可改造"，逐资产写，不合并 |
| 阶段式 beat 与 inline HEX | 第二段 | 用 `【阶段N：小标题】` 切分段内节拍（不等于剪切，连续单镜同样可用）；颜色写 `#RRGGBB` 内联到它所描述的光/物件上，不写"暗红光影"这类自然语言色 |
| 独立【声音设计】段 | 第二、三段之间 | 独立成段，按段内相对秒分层写人声、动作音效、环境声，并明确"仅生成…音效与环境音，不要 bgm"或指定 BGM |
| 【关键约束】具名铁律 | 第三段 | 每条约束起一个名字（机位铁律／身份铁律／光向铁律／道具铁律），一条一行，比散文式"保持一致"可执行 |
| 结尾 NOT 链 | 第三段末尾 | `NOT xxx+NOT yyy+…` 连写，收口本段最可能跑偏的形态；与无字幕/水印/Logo 兜底并存，不互相替代 |

`validate_delivery_md.py` 对正式段缺项给出警告而非硬错误：六件套是写作要求，机器只能
判断"有没有这个结构"，判断不了"写得对不对"，硬失败仍以人工与成片验收为准。

来源：真实上线成片提示词的逆向对照，非官方指南条款；与官方指南冲突时，本节只增补结构，
不覆盖官方三段论的信息顺序、主体定义法和台词真值规则。

## 5. 质量守卫

代码块末段必须覆盖：

- 真人实拍与整体视觉风格；
- 当前场景的物理光源；
- 当前最脆弱的人脸、嘴型、手或道具状态；
- 多人防分身、防双胞胎、防身份交换；
- 无字幕、无可见文字、无水印、无 Logo；
- 当前场景特有的轴线、道具、服装和光向约束。

分辨率由节点参数控制。不要把“高清、8K、细节丰富、电影质感、色彩自然、
光影柔和”作为固定套话，也不要把优化分析、内部账本或无关缺陷词复制进 LibTV。
