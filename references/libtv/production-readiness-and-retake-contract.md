# 生产准入、连续性与重拍合同

本合同定义 TVSkill 能够“根治”的范围：已知结构性错误必须在生成前被拦截；模型随机错误
必须在生成后被识别；带硬伤的成片不得交付，也不得成为后续连续性参考。不得承诺生成模型
每次一次成功。

## 1. 两种交付等级

每段必须标记：

- `预览`：仍须为每名说话人绑定审核通过的独立音色，只用于验证构图、动作和声画同步；
- `正式`：每名台词、OS、VO 或旁白说话人都必须绑定审核通过的独立音色并开启声音。

没有对应人物音色时，预览与正式都必须阻塞；风险披露、关闭声音或其它人物音色均不能替代。

阻塞的是**运行**，不是**编写**。音色由用户本人上传，未上传时按音色占位槽写法照常完成提示词与
Markdown：Mixed 表留占位行、段头写"音色状态：待关联"、"运行状态：阻塞"。占位段不同步、不运行；
用户上传后回读画布真实素材与顺序完成关联，改回可运行再走本合同的就绪判定。助手不得替用户
挑定音色，也不得把未经用户确认的候选音色写成"已绑定"。

## 2. 规划资产与生成资产分层

以下资产只供导演规划，严禁进入视频节点 Mixed：

- 位置图、轨迹图、平面图、俯视图、构图图和机位图；
- 带箭头、虚线、网格、编号、图例、文字标注、色块假人或 UI 的图；
- 多格分镜、接触表和同时展示动作前后状态的拼图；
- 与当前人数、道具或场景状态冲突的图片；
- 未验收或已拒绝视频的尾帧。

文字中的“不要继承箭头/文字/假人”不能豁免错误像素。规划图必须先转换并审核为以下
干净生成资产之一：

- `首帧-`：单一时刻、真人实拍式、无标记的构图状态板；
- `续接帧-`：上一段已验收视频的最后稳定帧；
- `场景状态-`：带明确占用人数、固定座位和光线状态的场景母版；
- `道具-`：单一实例、单一状态、无图示标记的定版道具图；
- 独立人物身份图、独立逐句音频或干净动作参考视频。

同一段只允许一个空间答案。需要可见全班时，使用已占座的 `场景状态-` 或干净首帧，
不得同时连接无人物空教室图。

## 3. 低自由度片段合同

绑定独立人物音色并开启原声的同步对白 Shot 必须满足：

- 每个 Shot 恰好一个说话人、一句或一个自然换气意群；
- 说话期间不走位、不转身、不递物、不做高速动作、特技或群体反应；
- OS/VO 不与同步对白同一个 Shot；
- 精确文字任务不与同步对白同段；
- 机位稳定但优先三分之四侧面或过肩构图，不能等同于正面播报；
- 使用干净 `首帧-` 或 `续接帧-` 提供真实眼神锚；只有“看向对方”不能通过；
- 最多一个有动机的可见身体变化，允许没有额外手部微动作；
- 每句最多一项声音变化。剧本未明确要求时使用自然口语；
- 六个汉字以内的短句一口气自然说完，不写语速慢、停半拍、一字一顿或拖长；
- 说完进入自然呼吸、倾听或继续原动作，不以“立即闭口并持续凝视不动”为唯一落点。

原生声画同出可以采用多镜路径，但每个 `Shot N:` 只允许一位说话人和一个自然
意群，并绑定该人物独立音色。高速道具、精确文字、复杂手部交互和群演高风险变化仍各自独立成段。
镜数按时间/空间事件密度决定，并按爆款短剧约 2.1 秒平均刀长校准：10–13 秒通常
4–7 个、14–15 秒通常 5–8 个清楚生成 Shot，2 秒镜为主、3 秒次之；不得仅因节点较短就
强制单镜。10 秒以上若使用连续单镜，必须写明不中断表演的长镜头叙事意图。

## 4. 人群、眼神与场景状态

出现可见学生、全班或群演时，必须记录：

- 固定可见人数或人数区间；
- 固定占座区域和主角预留座；
- 场景状态 ID、轴线和主光方向；
- 一个焦点反应，最多一个次级反应，其余人持续微动。

对白人物只有正面直视镜头的证件式参考时，不得直接进入正式近景对白。先增加同一人物
离镜视线的三分之四侧脸图或干净过肩首帧；否则降级为预览。

## 5. 道具实例与状态

关键道具使用唯一实例 ID，并记录 `owner / hand / location / orientation / state / count`。
同类多实例必须显式命名，例如：

- `PEN-A`：飞出后留在墙上；
- `PEN-B`：单知影手中转动；
- `REPORT-A-S0`：未批改；
- `REPORT-A-S1`：已圈画；
- `REPORT-A-S2`：定版结论。

模型不得从抽象无文字报告临场重绘精确文书。字幕、门牌、手机字、报告结论等精确文字
默认后期叠加；若必须在生成画面中出现，只能绑定已经含定版文字的静态道具图并保持，
不能要求模型生成、改写或补全文字。

## 6. 连续生成路线与受控接力

先选择能减少跨节点漂移的路线：

1. **单节点多镜**：同一时空的多事件链优先在一个节点内用 `Shot N:` 完成；
2. **视频延长**：单场长对话、情绪递进和单一路径移动，在 LibTV 实时 schema 暴露延长
   能力时，使用上一段已验收视频执行向后延长；
3. **受控独立剪辑**：剧情转折、新场景、高速道具、特效或精确文字任务才拆为独立节点。

不得要求两个独立生成节点在人物走动、转身、递物或摄影机运动的中间状态无缝拼接。
必须拆段时，把边界改到反应、视线对象、物件、动作完成或明显景别变化上。

连续性关键的同场片段禁止并发运行：

1. 只运行当前可运行片段；
2. 正常速度观看并逐帧检查；
3. 记录真实 `observed_start` 与 `observed_end`；
4. 接受后抽取最后稳定帧；
5. 下一片段同时绑定 canonical 人物/场景/道具锚和该 `续接帧-`；平台支持视频延长时，
   优先把已验收视频作为被延长对象；
6. 再运行下一片段。

尾帧接力只允许一跳，不能成为唯一身份来源；每两到三段或新的建立镜重新使用 canonical
场景状态母版。被拒绝片段不得进入接力链。时间跳切、反打或物件切可以声明独立重置，
改用新的干净首帧或场景状态母版。

Markdown 可以规划全集，但同一连续组最多一个片段标为“可运行”，后续必须标为
“等待上段验收”。只写“保持一致”不构成连续性方法。

## 7. 五道生产闸门

正式节点运行前依次通过：

1. 剧本忠实度：台词、说话人、OS/VO 类型和顺序逐字一致；
2. 制作路线：交付等级、声音、文字、人群、特技和后期路线明确；
3. 素材卫生：没有规划图、冲突场景、错误道具状态或未验收尾帧进入 Mixed；
4. 画布回读：提示词、入边、媒体数组和全部 Order 字段同序；
5. 连续性准入：前段已经验收，真实终态已记录，当前片段才可运行。

画布写入脚本必须在回读后立即执行同一套实时审计；发现任一硬错误时，本次同步整体视为
失败，不能只报告“节点已创建”。准备运行时生成 Markdown 审计凭证，记录节点实时输入
指纹。prompt、模型、settings、Mixed 顺序、任一媒体列表或任务状态变化后，旧凭证失效，
必须重新审计。运行授权不能只依据旧截图、Markdown 表或上一次通过记录。

## 8. 生成后硬伤与分流

以下任一项出现即为硬伤：错词或漏词、烧录字幕、乱码、箭头/图示、主角身份漂移、
人数突变、直视镜头、错误眼神目标、口型迟滞、道具穿模或悬浮、道具数量/持有者错误、
精确文字错误、首尾状态不可剪辑。

判定分为：

- 保留：主要叙事价值完成且无硬伤；
- 后期修复：声音、文字、色彩、裁切或少量尾帧属于后期职责；
- 局部编辑：只有一个画面层错误且平台支持编辑；
- 重抽：提示词正确、单次采样失常；
- 重写/拆段：同一硬伤出现两次，或任务本身过载。

一次重拍只改变一个主要变量。单片最多初次加两次定向重拍；仍失败时强制拆段、换资产、
改后期路线或重新设计镜头。不得继续堆负面词。

## 9. 正式验收

正式成片必须满足：

- 台词逐字正确，专名和数字人工复听；
- 无字幕、乱码、水印、Logo、箭头和图示；
- 主角身份、年龄、发型、服装和人数稳定；
- 眼神落在剧情目标，不直视镜头；
- 人群人数和占座状态前后一致；
- 道具实例、手别、正反面、版式和状态连续；
- 相邻末帧/首帧并排检查可剪辑；
- 后期路线需要的干净画面、空白文字区和声音余量完整。

## 低清试拍 → 高清定版

高风险段（复杂调度、变身、群像、巨物、跨时空转场）先用**低分辨率试拍**验证结构，通过后再高清定版。

- 试拍验的是**结构层**：构图关系立不立得住、身份认不认得出、动作过程有没有跳、空间朝向对不对。这些在低清阶段就必须成立。
- **结构层不成立时提高分辨率没有用**——那是提示词的问题，不是渲染精度的问题。返工要改失败变量本身，不能只加分辨率或追加否定词重跑。
- 试拍版本不进入 canonical，不作为续接帧来源，不参与下游绑定。
- 试拍通过后按正式参数定版，定版结果才写回账本并进入验收流程。

正式验收还必须回收同一范围内全部已生成版本，执行逐片十轴审计，并按剧本顺序装配复核。
完整方法见 [生成成片回收、质量审计与返工合同](generated-take-quality-audit.md)。
