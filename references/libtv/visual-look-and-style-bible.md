# 光影、构图、画面质感与风格母版

本文件是 TVSkill 自包含的视觉导演知识。它把风格拆成可复现的摄影变量，不把“电影感、
高级感、氛围感”当作可执行指令。风格不能替代人物、动作、空间或声音合同。

## 1. LOOK-ID

每部剧先建立一个 `STYLE-ID`，每个逻辑场再建立一个 `LOOK-ID`。同一场连续组重复使用
同一条短风格脊柱，不在每段随机换同义词。

`LOOK-ID` 至少锁定：

- 影像媒介：真人实拍、2D 动漫、3D CG、定格或其它明确媒介；全剧统一声明，中途不更换，并与资产图一致；
- 保真取向：**电影感不是唯一目标**。手机随手拍、监控画质、DV 家用带、伪纪录花絮等**刻意低保真**质感本身就是一种风格选择，用于花絮层、回忆层、证据层或戏中戏；选低保真时要显式写明它的画质特征（噪点、卷帘、自动曝光跳变、握持不稳），不要一边写"手机拍"一边又要求电影级光比；
- 成像基底：**保真取向选电影感一侧时，必须继续锁定一个具体基底**，不能停在「电影感 / 电影级」这种词上。可选基底、成像基线参数（黑位、高光滚降、颗粒、欠曝档数、锐度）与光学缺陷家族见 [成像基底与光学缺陷库](optical-substrate-library.md)；该库**不是全局默认**，低保真取向与风格化 3D 不适用。一个 `LOOK-ID` 只允许一个基底，更换基底视同 `LOOK-ID` 变体，须登记进连续性表；
- 慢动作与升格：属于**题材相关**选项而非全局规则。同一制作里某些段落禁用、某些高潮段落必用，取决于本段定位；不要把它写成全剧铁律；
- 时间与主光：光源种类、世界方向、软硬、色温关系；
- 对比与曝光：低/中/高对比，肤色与高光保护方向；
- 色彩：主色、辅色、禁止漂移色；
- 材质：皮肤、布料、木材、金属、玻璃和纸张如何响应光；
- 镜头：焦段倾向、景深、机位高度、稳定方式；
- 构图：权力轴、留白、前中后景和视线空间；
- 运动节奏：静、缓、急以及何时允许改变；
- 声音空间：房间底噪、混响距离和一个关键声音；
- 连续变体：同场的平静、压迫、揭示和余波如何在不换世界的前提下变化。

最终模型提示词只携带其中与本 Shot 有关的短脊柱；完整母版留在 Markdown 连续性表中。

### 1.1 媒介之后必须选择子风格

`3D CG`、`电影级`、`高精`、`PBR` 都不能单独构成 STYLE-ID；它们同时兼容仿真人数字人、风格化动画和潮玩卡通，模型会自行补全，常直接落到真人棚拍观感。

选择3D时必须继续锁定一个可见分支：

- 影视级国漫风格化3D：成人写实比例但面部结构适度概括，轮廓与眼神更利落；皮肤是干净的动画渲染面，不出现真人毛孔摄影；头发为设计过的发束，PBR用于服装与环境。
- 高端日韩风格化3D：比例更修长、面部更精致柔和，干净渐变阴影与受控高光；仍保持成人比例，不做大眼Q版。
- 仿真人数字人：真实毛孔、真实摄影棚灯光与接近真人的骨相；只有用户明确选择时才能使用。

正式资产前先生成一张风格定调图并由用户确认。该图是生成资产，不是规划图；确认后作为 STYLE-ID 真实父图连接到首层人物、场景和道具。没有真实风格父图时，不得声称“全剧风格已锁定”。

## 2. 物理光线

光线说明按“来源 → 方向 → 性质 → 作用”书写：

```text
右侧高窗自然日光作为主光，柔和侧照人物面部；室内顶灯只补环境亮度，
保持面部高光不过曝，背景木桌与绿板维持中等明暗层次。
```

规则：

- 主光必须能在场景中找到物理来源；
- 同场不随镜头任意换左右方向和色温；
- 对白反打保持同一世界光，只调整脸部可读性；
- 压迫感优先通过遮挡、负空间和明暗层次建立，不靠无来源彩灯；
- 皮肤不过度磨皮，保留自然纹理和轻微表情线；
- 白纸、白墙和窗户保护高光，避免大片死白；
- 金属、玻璃和笔尖只保留与主光一致的一次高光，不生成多重虚假反射。

## 3. 构图与权力

构图先服务关系，再服务漂亮：

- 权力占优者可获得更稳定的中心或更完整轮廓；
- 被压迫者可被前景、桌沿或门框轻度遮挡，但脸和眼神目标仍可读；
- 对峙使用明确左右和视线空间，不把两人都正面居中；
- 反打保留对方肩背或明确离镜目标，避免演员对空气说话；
- 揭示前保留负空间，揭示后用构图重新分配视觉重量；
- 群体场面使用前景一个明确反应、中景少量错开反应、背景持续微动；
- 竖屏中近景优先保护头顶、手部关键动作和视线空间，不把人脸长期锁死在正中央。

## 4. 画面质感

画面质感由真实表面和摄影响应构成：

- 肤色自然，毛孔与细小表情可见，不做蜡像式平滑；
- 制服、羊毛、西装、木桌、纸张和墙面保留各自纹理；
- 高光柔和滚降，阴影保留信息，不用纯黑压死；
- 景深用于组织注意力，不能让眼神目标和关键道具同时糊掉；
- 轻微传感器颗粒或自然运动模糊可以存在，但不能模拟脏镜头；
- 调色保持跨段一致，不能一段偏冷、一段泛黄、一段过饱和；
- “高清、8K、杰作、超细节”不属于质感指令，分辨率由节点参数负责。

风格化3D不套用真人皮肤条款：皮肤采用干净、连续的动画渲染面与受控次表面散射，不出现毛孔摄影、汗毛、真人皮肤噪声或棚拍磨皮感；“真实”只用于人体重力、材质反射和空间尺度，不用于把角色伪装成真人。

### 4.1 环境力锚

当一段戏处在**持续的环境力**中（风、雨、尘、雪、蒸汽、热浪），把它提升为**贯穿整段的锚**，而不是写一次氛围词就算数。否则模型只在起幅给一下，中段自行平息。

一条环境力锚包含三项：

- **持续声明**：写明它**全程存在且不减弱**，并给出方向与强度；
- **可见证据**：指定**至少两处**受它持续影响的可见对象——发丝、衣摆、帘幕、旗面、地面浮尘、水面涟漪；证据要绑在画面里实际存在的东西上；
- **声画同写**：同一环境力在音轨层也要有对应的持续声，并说明它与对白的压制关系。

环境力锚属于 `LOOK-ID` 的一部分，同一逻辑场内跨段保持一致；它变化时视同 `LOOK-ID` 变体，必须在连续性表中登记。

### 4.2 反油腻与反游戏感

史诗、古装、武侠、科幻、幻想、巨型建筑与妖怪题材上，模型的默认落点是**游戏概念图**，
不是实拍剧照。这类题材必须**主动压低视觉奇观词**，改写实拍质感词，否则画面会油亮、
过度精致、材质失重，人物像穿着游戏皮肤摆英雄站姿。

**优先写（正向词表）**：实拍电影剧照；真实外景或实景搭建；自然曝光；可见光源；
哑光石材；氧化金属；粗麻布、旧皮革、磨损木材；灰尘、烟、风、汗、泥、划痕、脚印；
服装有重量和使用痕迹；人物疲惫、克制、正处在动作过程中。

**禁止写（自查词表，命中即重写该句）**：`epic`、`ultra detailed`、`masterpiece`、
`hyperreal`、`8k`、`volumetric fantasy`；英雄站姿、宣传海报感、boss 登场；
发光轮廓、魔法边缘光、无来源蓝橙双光；`glossy`、`polished`、`sleek`、`shiny`、
`perfect surface`；`Unreal Engine look`、`CGI render`、`game cinematic`、
`concept art`、`digital painting`。该词表与
[约束编译](../v3/04c-constraint-and-negative-prompt-compiler.md) 四之二互为一体。

需要在末段收口形态时，走 [完成提示词规范](libtv-completed-prompt-format.md) 的 NOT 链，
写 `NOT CGI render+NOT game cinematic+NOT concept art+NOT glossy specular highlights`
一类**形态词**；不写缺陷词，不因为加了 NOT 链就挤掉每镜最小画面基底。

**画面偏油腻/过度琥珀时的定向校准**（只改这几项，不要同时换模型和重写表演）：

- 把「暖金色电影光」改成「老化钨丝实景灯，暖但脏、输出低」；
- 暖色只允许出现在灯具、窗边、火光或局部反光，不铺满全图变成蜂蜜金；
- 颗粒集中在阴影和中间调，细到中等、自然不匀，不做统一颗粒贴纸；
- 降低肤色、布料、抛光木材、黄铜、水面反光的饱和与光泽；布料必须吸光；
- 石材、灰泥、木材、金属必须有时间痕迹：污垢、氧化、划痕、剥落、盐渍、烟熏、水痕；
- 若灯具或窗口开始像柔光美颜滤镜，把 bloom / halation 直接减半。

**单一主导瑕疵家族**：脏污要选择性，不是越脏越真。一组连续镜头只允许一个主导瑕疵家族——
灰尘与干划痕、雨与湿反光、烟与低输出灯、荧光灯管的机构性油污、视频噪波、
起雾玻璃与冷凝、日晒褪色与剥漆——**不得把多种脏污模式堆在同一画面**。
持续性的环境力（风、雨、尘、雪、蒸汽）仍按 §4.1 环境力锚的三件套书写，
瑕疵家族管的是质感层，环境力锚管的是叙事层，两者不互相替代。

## 5. 镜头运动与表演

- 对白和细微表演以稳定机位为主；若运动，只有一次有动机的缓慢调整；
- 高速道具先保证轨迹、接触和落点，镜头运动让位；
- 紧张不等于持续推近；可以用静止、遮挡和更紧的视线空间；
- 机器人感常来自正面居中、演员停住等台词、句句规定语气和无因慢推；
- 自然表演保留听、想、说、恢复呼吸的链条，身体允许不动；
- 同一段不得同时要求复杂走位、精确眼神、长台词、群演反应和明显运镜。

## 6. 风格脊柱模板

```text
LOOK-ID：<名称>
真人实拍；<时间/地点>；<主光来源与方向>；<对比与色彩>；
<皮肤与材质>；<焦段/机位/景深>；<构图关系>；<运动节奏>。
```

模型代码块压缩为一到两句：

```text
沿用 LOOK-ID <名称>：真人实拍，右侧高窗柔和日光，中等对比，
自然肤色与真实制服、木桌、纸张纹理；稳定平视机位，以视线空间组织权力关系。
```

## 7. 现代精英学院教室配方

适用于 Z 班此类现代学院权力文戏，属于 TVSkill 内部制作配方，不冒充模型官方预设：

- `STYLE-ID`：现代精英学院写实短剧；
- `LOOK-ID`：学院教室-白日-冷静压迫；
- 媒介：真人实拍，克制的商业剧情摄影；
- 光：右侧高窗柔和自然日光为主，顶灯弱补；主光方向全场固定；
- 色：深蓝制服、偏中性的木桌、低饱和绿板和浅灰墙，避免糖果色与无来源青橙；
- 对比：中等对比，人物脸部可读，窗和白纸不过曝；
- 材质：自然皮肤、制服织物、木桌划痕、纸张纤维和钢笔金属高光；
- 镜头：平视或轻微低机位，中近景和过肩为主，浅到中等景深；
- 构图：单知影的静与他人的扰动形成对比；李威的攻击通过占画和前景压力表现；
- 运动：大部分稳定，权力变化时才允许一次缓慢重构；
- 群演：占座密度固定，低幅持续微动，不同步表演；
- 功能朝向：黑板和讲台固定前墙，课桌、座椅与学生下半身统一面向黑板；后排朝前墙机位
  只见学生背面或后侧三分之四，完整正脸改用前墙反打或侧前方机位；
- 禁止：空教室替代全班、偶像剧过度柔光、蜡像磨皮、随机冷暖漂移、持续正面口播。

## 8. 风格连续性审计

逐段接触表并排检查：

- 主光是否仍来自同一世界方向；
- 制服、墙、桌、绿板和肤色是否漂色；
- 人群密度和背景尺度是否一致；
- 相邻景别是否存在无动机焦段跳变；
- 肤质、锐度、颗粒和运动模糊是否突然变化；
- 镜头运动是否符合情绪弧，而非每段机械重复。

若风格失败，只修改与失败有关的一个变量。不要同时换模型、换全部参考、重写表演和改变
色彩；否则无法确认有效因果。
